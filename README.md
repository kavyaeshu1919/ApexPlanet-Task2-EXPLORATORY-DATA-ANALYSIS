# Task 2: Exploratory Data Analysis (EDA) & Business Intelligence

## Project Overview
This project is completed as part of the ApexPlanet Data Analytics Internship. The objective of this task is to perform Exploratory Data Analysis (EDA) on a cleaned sales dataset to identify trends, patterns, and business insights using Python.

## Objectives
- Perform descriptive statistical analysis.
- Explore numerical and categorical data.
- Create data visualizations.
- Identify business trends and insights.
- Prepare a dashboard mock-up.
- Write SQL queries for business analysis.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Microsoft PowerPoint
- GitHub

## Dataset
The analysis is performed on the cleaned sales dataset prepared in Task 1.

## Work Completed
- Data Exploration
- Descriptive Statistics
- Histogram of Age Distribution
- Sales by Category Analysis
- Top 5 Products Analysis
- Top 5 Cities Analysis
- Gender Distribution Analysis
- Business Insights
- SQL Query Preparation
- Dashboard Mock-up
